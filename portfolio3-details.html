Project Details

Deaf Sign Language Prediction



About the Project: This project is a machine learning-based application designed to recognize and translate American Sign Language (ASL) alphabets (A–Z) from hand gesture images. It aims to bridge communication gaps between deaf individuals and others by enabling quick and accurate alphabet prediction.

Problem: Communication barriers make it difficult for deaf and mute individuals to interact with those unfamiliar with sign language. Real-time translation tools are often expensive or not easily accessible.

Solution: The system uses image processing to convert hand gesture inputs into a 28x28 grayscale format and then predicts the corresponding alphabet using a trained machine learning model. It provides a low-cost, efficient way to recognize sign language through visual input.

Technologies Used: Programming Language: Python
Libraries: NumPy, OpenCV, TensorFlow
Model Type: Convolutional Neural Networks(CNN)
Dataset: ASL Alphabet Dataset

Features : The application captures and preprocesses hand gesture images, classifies them into alphabets (A–Z), and displays the predicted output in real-time. It’s lightweight, extendable, and serves as a base for building full-fledged sign language translators for words and sentences.
